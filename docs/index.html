CHZZK Manager Chat 개인정보처리방침

시행일: 2026년 5월 14일

1. 개요

CHZZK Manager Chat은 치지직 라이브 채팅에서 매니저 채팅을 별도 영역에 표시하기 위한 Chrome 확장 프로그램입니다.

2. 수집하는 개인정보

이 확장 프로그램은 사용자의 개인정보를 개발자 서버로 수집, 저장 또는 전송하지 않습니다.

3. 브라우저 내부에서 처리되는 데이터

이 확장 프로그램은 치지직 페이지에서 브라우저가 수신한 채팅 이벤트를 브라우저 내부에서만 처리합니다. 처리 목적은 매니저 채팅 여부를 판단하고 해당 메시지를 화면에 표시하는 것입니다.

  • 채팅 메시지 내용
  • 채팅 작성자 닉네임
  • 채팅 작성자의 역할 정보
  • 메시지 수신 시각

4. 데이터 저장

이 확장 프로그램은 사용자가 조정한 패널 표시 여부와 패널 높이 같은 설정값만 Chrome의 로컬 저장소에 저장할 수 있습니다. 채팅 내용은 외부 서버에 저장하지 않습니다.

5. 제3자 제공

이 확장 프로그램은 어떠한 개인정보나 채팅 데이터를 제3자에게 판매, 공유 또는 제공하지 않습니다.

6. 외부 전송

이 확장 프로그램은 채팅 내용, 계정 정보, 방문 기록 또는 기타 사용자 데이터를 개발자 서버나 제3자 서버로 전송하지 않습니다.

7. 권한 사용

이 확장 프로그램은 치지직 페이지에서 동작하기 위해 해당 사이트 접근 권한을 사용하며, 설정 저장을 위해 Chrome 저장소 권한을 사용합니다.
