# CHZZK Manager Chat

치지직 방송 페이지의 채팅창에서 매니저 채팅만 별도 패널로 모아 보여주는 Chrome MV3 확장 프로그램입니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
4. 이 폴더를 선택합니다.
5. 치지직 방송 페이지를 새로고침합니다.

## 사용

- 방송 페이지의 라이브 채팅창 내부 상단에 `매니저 채팅` 영역이 표시됩니다.
- 치지직 채팅 레이아웃을 찾지 못한 경우에는 패널을 표시하지 않습니다.
- 라이브 채팅처럼 오래된 채팅이 위, 최신 채팅이 아래에 쌓입니다.
- 스크롤이 최하단에 있을 때만 새 메시지를 자동으로 따라갑니다. 위로 올려 이전 채팅을 보는 동안에는 자동 스크롤이 멈춥니다.
- 오른쪽 위 `−` 버튼으로 접거나 펼칠 수 있습니다.
- 매니저 채팅 영역과 라이브 채팅 영역 사이의 경계선을 드래그해서 높이를 조절할 수 있습니다.
- 확장 프로그램 아이콘을 누르면 패널 표시를 켜고 끌 수 있습니다.

## 감지 방식

페이지의 WebSocket 채팅 이벤트만 감시합니다. 채팅 프로필의 `userRoleCode`가 `streaming_chat_manager`, `streaming_channel_manager`, `manager`이면 매니저 채팅으로 분류합니다.

화면에 렌더링된 채팅 DOM은 수집하지 않습니다. 그래서 채팅창을 위로 올려 과거 채팅이 다시 렌더링되어도 새 메시지로 중복 수집하지 않습니다. 확장 프로그램을 켠 뒤 치지직 방송 페이지를 새로고침해야 가장 먼저 WebSocket을 잡을 수 있습니다.
